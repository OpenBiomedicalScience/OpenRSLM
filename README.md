# OpenRSLM

OpenRSLM is an open-source regulated software lifecycle,
traceability, quality management and audit-evidence platform
developed by the Open Biomedical Science Foundation.

> [!IMPORTANT]
> OpenRSLM supports regulated development workflows but does not,
> by itself, make an organization or product compliant with FDA,
> ISO 13485, IEC 62304 or other regulatory requirements.

## Project status

Early development. Not yet validated for production quality-system use.
